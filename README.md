# 筑波宇宙センター特別公開2026 マイスケジュール（非公式）

2026年11月28日（土）の JAXA 筑波宇宙センター特別公開で、行きたいイベントや当選したイベントを選んで自分の予定表を作る Web アプリです。

- 公開 URL: https://fu-ji-p.github.io/tksc-openday2026/
- 公式サイト: https://visit-tsukuba.jaxa.jp/2026openday/index.html

個人が作成した非公式ツールで、JAXA 公式のものではありません。
内容は 2026-11-17 時点の公開情報をもとにしています。申込や来場の前に必ず公式サイトで最新の情報を確認してください。

## できること

| 画面 | 内容 |
|---|---|
| タイムテーブル | 全イベントを「場所 × 時刻」の表で見る。終日のイベントは細い列。色は参加方法（事前申込・整理券・先着順・申込不要） |
| イベント一覧 | 全 57 イベントをエリア・参加方法・カテゴリ・キーワードで探す |
| 予約・整理券 | 事前申込 14 件を締切の近い順に一覧。締切、抽選/先着順、結果通知の時期、予約ページへのリンク。自分の申込状況（未申込/申込済/当選・予約確定/落選）を記録。当日整理券の配布時間と場所 |
| マイスケジュール | 選んだ回を時刻順に表示。重複、エリア移動、申込や整理券の確認事項を表示。カレンダー（.ics）書き出し、印刷 |
| ⚙ 設定 | 別の端末へ送る共有リンク、JSON の書き出し/読み込み、全消去 |

出入り自由のイベントは「いつでも行けるイベント」として登録され、詳細画面で「行く時刻」を決めると時刻順の予定に入ります。

## データの保存

選んだ予定と申込状況のメモは、ブラウザの localStorage（キー `tksc-openday2026.schedule.v1`）にだけ保存します。サーバーには送りません。

- 端末やブラウザをまたいでは引き継がれません。当日使うスマホで登録するのが確実です。
- パソコンで作った場合は、⚙ 設定の「リンクをコピー」でスマホへ送れます。
- ブラウザのサイトデータを消すと記録も消えます。

利用状況の把握のため、訪問数だけを GoatCounter（Cookie なし）で匿名計測しています。予定や申込メモの内容は送信しません。

## 開発

```bash
npm ci
```

```bash
npm run dev
```

```bash
npm test && npm run build
```

Vite + React + TypeScript、UI ライブラリなし。`main` に push すると GitHub Actions がテスト・ビルドして GitHub Pages に公開します。

### データの更新

イベント情報は `data/program.json` だけで決まります。公式サイトの更新（申込方法の発表、時間の変更など）を取り込むには次を実行します。

```bash
python3 scripts/build_program.py
```

- 公式サイトのイベントデータを取得して `data/program.json` を作り直します。
- 前回から時間・場所・申込情報が変わったイベントを警告します。警告が出たら、スクリプト内の `OVERRIDES`（各回の時刻、抽選/先着、結果通知の時期、ひとこと紹介）を見直します。
- 公開後はセッション ID（`14/2` など）を変えないでください。利用者の保存データのキーになっています。

更新のたびに `package.json` の version と `CHANGELOG.md` を更新し、同じ番号のタグを付けます。詳しくは [docs/SPEC.md](docs/SPEC.md)。
